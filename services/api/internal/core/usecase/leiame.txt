Diário SG — dump da base
=========================

Cópia completa, refeita toda semana, do que o Diário SG extraiu do Diário
Oficial do Município de São Gonçalo (RJ). Não é publicação da prefeitura;
a edição oficial em PDF é que vale.

Arquivos (CSV, separador vírgula, UTF-8, compactados com gzip)
--------------------------------------------------------------

gazettes.csv.gz — uma linha por edição
  id              identificador da edição no Diário SG
  edition_number  número da edição (vazio quando o PDF não traz)
  published_at    data de publicação (AAAA-MM-DD)
  is_extra        true para edição extraordinária
  source_url      PDF no site da prefeitura
  pdf_sha256      SHA-256 do PDF coletado
  indexed_at      quando a edição foi indexada (UTC)

acts.csv.gz — uma linha por ato
  id              identificador do ato (muda quando a edição é reprocessada)
  gazette_id      edição do ato (gazettes.id)
  position        ordem do ato na edição, a partir de 0
  type            nomeacao, exoneracao, contrato, aditivo, licitacao,
                  dispensa, decreto, lei, portaria, resolucao, despacho,
                  edital, ata, corrigenda, prestacao_contas, outro
  organ           sigla do órgão (vazia quando não identificada)
  title           título do ato
  page_start      página do PDF onde o ato começa (vazia se desconhecida)
  page_end        página do PDF onde o ato termina
  body            texto do ato como extraído do PDF

act_entities.csv.gz — dados extraídos do texto de cada ato
  act_id          ato (acts.id)
  kind            cnpj, valor, contrato ou processo
  value           como aparece no texto
  normalized      só dígitos; para valor, em centavos

manifest.json traz a data do dump e, para cada arquivo, linhas, bytes e
SHA-256.

Para ligar um ato entre dumps diferentes use (gazette_id, position): o id
do ato muda quando a edição é reprocessada com uma versão nova do parser.

Como abrir
----------

Python (pandas):
  import pandas as pd
  atos = pd.read_csv("acts.csv.gz")

SQLite / Datasette (sqlite-utils):
  gunzip -k acts.csv.gz gazettes.csv.gz act_entities.csv.gz
  sqlite-utils insert diario.db gazettes gazettes.csv --csv
  sqlite-utils insert diario.db acts acts.csv --csv
  sqlite-utils insert diario.db act_entities act_entities.csv --csv
  datasette diario.db

Responsabilidade
----------------

Os atos são documentos oficiais e públicos, mas citam pessoas de verdade.
A LGPD vale para quem reutiliza: não monte perfis de pessoas físicas a
partir destes dados e cite sempre a edição original. O texto extraído pode
ter erros de extração; confira no PDF.
